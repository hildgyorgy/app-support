About

MusicBrainz Explorer is a release and discography browser built around MusicBrainz metadata, detailed credits and clear navigation.

It can match and play MusicBrainz-tagged music from a local folder or Navidrome. Playback is optional; the Explorer remains fully usable without a library.

System requirements

MusicBrainz Explorer runs in a modern browser with JavaScript enabled. Local-folder playback requires supported tagged files; Navidrome playback requires an accessible OpenSubsonic server.

Setup and playback

Select the pulsing logo on the start page to open search help and playback setup.

  • Source: choose a local music folder or connect Navidrome.
  • For local playback, create or load library.json. Albums are identified from embedded MusicBrainz IDs, never folder names.
  • MusicBrainz compatibility: review which albums are correctly identified and which need better tags.
  • Output: use system audio or a discovered UPnP renderer when the local bridge is running.
  • Play symbols mark matched releases and tracks; the floating player stays available while you browse.

Audio playback

With system audio, the Explorer plays the original selected file through the browser's native audio pipeline and does not deliberately transcode it.

Because the browser, operating-system mixer and chosen audio device remain part of the playback chain, bit-perfect output cannot be guaranteed.

Privacy Policy

  • MusicBrainz Explorer has no application backend or user accounts.
  • Your music files and library.json are not uploaded by the app.
  • Browser indexing and playback happen locally on your device.
  • The app does not retain folder access after the page session ends.
  • A Navidrome password is kept only for the current page session; the saved connection profile does not include it.
  • Music metadata and cover art are requested from MusicBrainz and the Cover Art Archive.
