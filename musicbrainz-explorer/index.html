MusicBrainz Explorer

Explore releases. Play your own library.

About

Browse MusicBrainz releases, editions, discographies and track credits. Connect a music library if you want to play matching releases.

System requirements

Use a modern browser with JavaScript enabled. For playback, use MusicBrainz-tagged audio files in a local folder or a reachable Navidrome server with OpenSubsonic support.

Setup and playback

Open Setup with the start-page logo or the gear in the header.

  • Under Source, choose Local or Navidrome. Select the active option again to open its settings.
  • Use MusicBrainz compatibility to review tagging in the selected library. Play icons mark playable tracks and editions in Versions. In an artist’s discography, a play icon means at least one edition is playable.
  • Under Layout, choose the default single-column Focus view or the two-column Desktop view, with editions on the left and tracks on the right.

For a local library, run Create Library Index from the Local settings and choose your music folder. If the browser downloads the files, put library.json and library-report.json in that folder. To load an existing index or reconnect later, choose Connect Music Folder and select the same folder.

Navidrome

In the Navidrome settings, fill in Navidrome URL, Username and Password, then choose Save & Connect.

  • Navidrome URL is the HTTPS address for catalogue access and browser playback in the hosted Explorer. A Tailscale Serve URL works here.
  • Local URL for UPnP is optional. With it, the renderer streams directly from Navidrome. Leave it blank to let the Bridge relay the stream.
  • The status below the buttons shows the connection in use. Leave the password blank to reuse a saved login.

Explorer reads the Navidrome catalogue directly without a local index. Albums need MusicBrainz release IDs. Tracks also need recording IDs and accurate disc and track numbers. Open the MusicBrainz compatibility report below the connection status to see which albums still need tags.

Audio playback

System audio plays through your device’s current sound output, including speakers, headphones or a USB DAC. Explorer requests the original Navidrome stream. The browser and system mixer can still affect the output.

UPnP Bridge

Use the Bridge on an Apple Silicon Mac to play Navidrome music through a UPnP renderer on the same local network.

  1. Install. Open the latest Bridge DMG, drag the app to Applications, then launch it. Allow local network access if macOS asks.
  2. Set up. Open the bundled Explorer from the Bridge menu and use http://127.0.0.1:9181 as the Bridge URL. For the hosted Explorer, use the Mac’s Tailscale Serve HTTPS address instead.
  3. Play. Connect Navidrome, select your device under Output → UPnP renderer, and start a playable track. Keep the Bridge running.

Privacy Policy

  • MusicBrainz Explorer has no application backend or user accounts.
  • Local files and indexes stay on your device. Supported browsers can remember the selected folder and may ask for access again.
  • Explorer connects to the Navidrome server you configure. With UPnP, the renderer streams from Navidrome directly or through your Bridge.
  • The browser stores your Navidrome settings and a reusable salted login token. Your original password is not stored.
  • Music metadata and cover art are requested from MusicBrainz and the Cover Art Archive.
