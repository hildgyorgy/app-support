# App Support

Statikus, GitHub Pages-kompatibilis support site György Hild alkalmazásaihoz. Az oldalak közös, rendszerbetűtípusokra és automatikus világos/sötét megjelenésre épülő arculatot használnak.

## Helyi előnézet

Nyisd meg az `index.html` fájlt egy böngészőben, vagy indíts egy egyszerű helyi webszervert a projekt mappájában.

## Közzététel GitHub Pages-en

A repository **Settings → Pages** oldalán válaszd a **Deploy from a branch** lehetőséget, majd a `main` branch `/ (root)` mappáját.

## Tartalom szerkesztése

- A főoldal: `index.html`
- Az alkalmazások oldalai: az alkalmazás nevével azonos mappákban lévő `index.html` fájlok
- Közös megjelenés: `assets/css/style.css`
- Appikonok: `assets/images/`

A kapcsolat hivatkozások a support e-mail-címre vezetnek.
