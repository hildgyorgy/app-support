Support and privacy information

About

MusiRender turns your Mac into a UPnP/DLNA audio renderer. Browse your library in a controller such as MusiCards or mconnect Player, select MusiRender as the playback device, and listen through the Mac’s current audio output. A UPnP/DLNA media server such as Gerbera can provide the music library.

Use the menu bar, the compact player window or macOS Now Playing to control playback. MusiRender can keep playing with its window closed.

System requirements

MusiRender requires an Apple silicon Mac running macOS 26 Tahoe or later. Connect the Mac, controller and media server to the same local IPv4 network.

First setup

  1. Open the notarized DMG, drag MusiRender to Applications and open the app.
  2. Allow local network access if macOS asks. Click the speaker icon in the Mac menu bar to check that MusiRender is Online.
  3. In your controller, select your media server as the library and MusiRender as the playback device.
  4. Start a track from the controller. To change where it plays, select the device in System Settings → Sound → Output.

Playback and audio information

  • The Source line shows the source server and the track’s format, sample rate, bit depth and estimated bitrate when available.
  • The Output line shows the current macOS audio device, such as the built-in speakers, Bluetooth headphones or a USB DAC.
  • Gapless playback depends on the controller queuing the next track in advance and on the stream format and buffering.

Support

If MusiRender does not appear in your controller, check that it is Online, that local network access is enabled for both the Mac app and the controller, and that your network allows the devices to reach each other. Guest Wi-Fi may isolate devices.

Some controllers manage their own playback queue. Use the controller’s track buttons if the corresponding controls are unavailable in MusiRender. For playback issues, open Diagnostics in MusiRender and include the relevant entries, your macOS version, and the names of the controller and media server when contacting support.

Privacy Policy

MusiRender requires no app account and contains no advertising, analytics or developer-operated crash reporting.

  • MusiRender uses the local network to announce itself and receive playback commands from UPnP/DLNA controllers.
  • The app fetches audio and available artwork from the URLs supplied by your controller. Those requests go directly to the hosts that serve the content.
  • App settings are stored on your Mac. Recent diagnostic entries are kept in memory, and credential-like URL query values are redacted in those entries.
  • Playback and diagnostic data are never sent to the developer automatically.
